# Receipt-Printer-for-Productivity
hi. i have a very short attention span and i don't really like having a calendar and writing things down. i thought it would be cooler to buy one of those receipt printers they have at resturants and print out receipts and have somewhere to stab them when im done. that way I can physically see my tasks.

The concept of the project is a reciept printer that prints out your daily tasks or notes. Everytime you hit enter it prints out your task on the printer so you can physically see it, like how resturants recieve orders.

1. You can use a 58mm or a 80mm thermal printer, I am using the 'NetumScan USB POS Receipt Printer, 80mm Thermal Receipt Printer'. But I bought 58mm receipts so the code is for 58mm. All that you have to change is the formatting of the lines if you have a bigger receipt your printing on.
2. Get a spike or 3D print one so you can stab your receipts into. Or just have a physical way of tracking the goals you get done.
3. Use Notepad ++ with auto backup, Notepad++ is alot easier and nicer to use than regular Notepad.
4. Install python

Type 'pip install pywin32' in your console to get the  python dependencies

After installing the code and the dependencies type 
'python spike_print_server.py'

I have some Aperture Science ASCII art in the code so that it prints it on each receipt. You can delete it or change it to whatever acii art you want, especially since mine isn't the greatest.

Into your console, then open up Notepad ++ and have fun :)
